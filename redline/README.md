# Redline — maquette UI

Maquette de l'interface de Redline (outil de revue de code généré par IA) :
écran de configuration (wizard) + dashboard de surveillance temps réel.

⚠️ Les données affichées (alertes, détections) sont encore **simulées** : cette
maquette sert de cahier des charges UI avant branchement sur le vrai backend
(`backend-express`).

## Lancer le projet

```bash
npm install   # installe les dépendances
npm run dev   # démarre le serveur de développement
npm run build # typecheck (tsc) + build de production
```
